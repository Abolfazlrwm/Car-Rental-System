Salted SHA-256 auth, ISO calendar dates, double-booking prevention, late-return penalties, a waitlist that auto-books freed slots, a tiered loyalty program, CSV & JSON reports, a live analytics dashboard and an audited permission matrix. ▸Highlights

Real calendar dates

Bookings, returns and maintenance logs speak strict YYYY-MM-DD — leap years included. Data files from older versions still load.

Security done properly

Salted SHA-256 password hashing verified against official FIPS 180-4 vectors, auto-lockout after 3 failed logins — and since 2.5.0 a 7-permission matrix enforced inside the facade, with every privileged action and denial landing in an append-only audit trail.

Booking rules that hold

Date-range overlap rejection, earliest-pickup-first scheduling with FIFO ties, renewal blocked while others wait — and since 2.6.0 a per-car waitlist that auto-books the best-fitting wish the moment a return frees the window.

Loyalty that earns its rank

Since 2.7.0 completed rentals pay 1 point per 10.00 spent at the rank's multiplier (Bronze → Platinum, up to ×2.0), ranks grow on lifetime points, and 10 points turn into 1.00 off the outstanding bill — every earn and redemption audited.

Money with an audit trail

Automatic invoicing, 1.5× late-day penalties charged exactly once, customer balances, per-car income ledger.

CSV everything

Full state round-trip in data/*.csv, plus manager-exported fleet & bookings reports into reports/.

Tested like it matters

4,804 dependency-free checks — every v1.0 bug is now a regression test — green under AddressSanitizer + UBSan on every push.
